# 🍅 Tomato MandiMart - PHP/MySQL Project

## Complete Farmer-to-Buyer Tomato Marketplace

### Tech Stack
- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
- **Backend:** PHP 7.4+ with MySQLi
- **Database:** MySQL 5.7+ / MariaDB 10.3+
- **Server:** Apache with mod_rewrite

### Features
- ✅ Live Mandi Prices (AJAX loaded)
- ✅ Farmer Crop Listings with image upload
- ✅ Real-time Auctions with bidding
- ✅ AI Quality Comparison (demo)
- ✅ Product Comparison Tool
- ✅ Chatbot with Hindi/English support
- ✅ User Authentication (Farmer/Buyer/Admin)
- ✅ Admin Dashboard
- ✅ Responsive Design
